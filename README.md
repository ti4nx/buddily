# Buddily

**Buddily** is a modern productivity and task-management app built around the **Eisenhower Matrix**.

It helps users organize tasks based on two simple factors:

* **Urgency**
* **Importance**

Instead of keeping everything in one long to-do list, Buddily separates tasks into four clear priority groups so users can quickly understand what needs attention first.

## Product Purpose

Buddily is designed to make task prioritization easier.

The app helps users decide whether a task should be:

* Done now
* Scheduled for later
* Delegated
* Removed

The goal is to reduce clutter and make it easier to focus on work that actually matters.

## How the Eisenhower Matrix Works

Buddily organizes tasks into four quadrants.

### Do

**Urgent and Important**

These are tasks that require immediate attention.

Examples:

* Fixing an urgent work issue
* Completing a deadline due today
* Responding to an important time-sensitive request

### Schedule

**Important but Not Urgent**

These tasks are valuable but do not need to be completed immediately.

Examples:

* Planning a project
* Studying
* Exercising
* Preparing for an upcoming deadline

### Delegate

**Urgent but Not Important**

These tasks may need to be completed soon but do not necessarily require your personal attention.

Examples:

* Routine requests
* Administrative tasks
* Work that can be assigned to someone else

### Delete

**Not Urgent and Not Important**

These tasks have little value and may be removed from your workload.

Examples:

* Unnecessary activities
* Low-value distractions
* Tasks that are no longer relevant

## Key Features

### Four-Quadrant Task Board

The main Buddily interface displays tasks based on their Eisenhower Matrix category.

This allows users to immediately see which tasks deserve the most attention.

### Task Creation

Users can create tasks and assign them to the appropriate priority quadrant.

Tasks can include relevant details such as:

* Task title
* Description
* Priority category
* Due date
* Notes
* Status

Available fields may vary as Buddily continues to develop.

### Task Completion

Completed tasks can be marked as finished so users can keep their active task list focused and organized.

### Profile Customization

Users can personalize their Buddily profile with a selectable profile avatar.

### Account Access

Buddily uses email-based account access.

The app intentionally keeps personal information requirements minimal.

## How to Use Buddily

### 1. Sign In

Open Buddily and sign in using your account.

Your email address is used to identify and authenticate your account.

### 2. Create a Task

Add a new task by entering the task details.

Before assigning the task, ask yourself two questions:

**Is this task important?**

**Is this task urgent?**

Your answers determine where the task belongs.

### 3. Choose a Quadrant

Place the task into one of the four Buddily categories:

* **Do**
* **Schedule**
* **Delegate**
* **Delete**

### 4. Review Your Priorities

Use the main task board to review your workload.

A useful order of attention is generally:

1. Do
2. Schedule
3. Delegate
4. Delete

This helps prevent low-value tasks from taking attention away from important work.

### 5. Complete Tasks

Mark a task as complete once it is finished.

Keeping completed work separate from active work makes it easier to focus on what remains.

### 6. Reorganize When Needed

Priorities can change.

A task that was previously not urgent may become urgent as its deadline approaches.

Review your matrix regularly and update tasks when necessary.

## Example

Imagine you have the following tasks:

| Task                           | Category |
| ------------------------------ | -------- |
| Submit a report due today      | Do       |
| Prepare for an exam next month | Schedule |
| Ask someone to print documents | Delegate |
| Reorganize an unused folder    | Delete   |

Instead of seeing four unrelated tasks in one list, Buddily immediately shows which one deserves your attention first.

## Recommended Workflow

For everyday use, Buddily works best when you:

1. Add new tasks as they come up.
2. Decide whether each task is urgent and important.
3. Place each task in the appropriate quadrant.
4. Focus on the **Do** quadrant first.
5. Plan time for **Schedule** tasks.
6. Delegate suitable tasks when possible.
7. Review whether **Delete** tasks need to exist at all.
8. Update your matrix as priorities change.

Buddily does not sell user information or use personal information for targeted advertising.
